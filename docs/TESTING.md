## 记录规则
每轮复制 [RUN_TEMPLATE](testing/RUN_TEMPLATE.md) 为独立记录；test ID、应用commit/补丁、APK SHA256、资源哈希、系统配置、合成数据种子、命令、实际输出、预期/实际和证据链接不可缺。禁止输入真实密码/个人词库。主机规格/文档检查只覆盖项目准备，不证明 Android 行为。当前结果见 [初始化记录](testing/INIT-20261023.md)。

状态：PASS 有实际证据；FAIL 已执行不符；BLOCKED 缺必要条件；NOT_RUN 未执行。N/A 必须具体理由，不能用于绕过 P0/P1。无设备或截图保留阻碍；记录有样本量、非猜测的延迟/排名。

## 语料与可复现性
`tests/fixtures/seed_cases.json` 只是少量合成探针，**不是**100词20句完整评测集。M3在看结果前增加固定语料/预期集合，禁用个人词库与日期/随机模块；对多种合理候选记录Top5集合，不要求语言引擎逐字照mock。学习集单独隔离，测试前后profile使用临时目录。性能不在debug或host模拟器成绩上替代Pixel release数据。

## 发布检查
文档结构/工具测试通过 → Android单元/lint/native构建通过 → 真引擎/宿主集成 → 所有P0安全 → Pixel/参考视觉与性能 → 全回归 → 同一release哈希签收。无截图则S/D视觉BLOCKED，无设备则D/P真机BLOCKED，不合并成“全部通过”。重要失败必须复现并修复，保存失败历史，不覆盖旧结果。截图差异算法是辅证，不能替代用户体验验收。

敏感结构删除增量：隐私策略禁止正文读取、允许必要结构信息，U05的“上下文口”指文字正文读取。正文getter与结构请求分别计数；合成宿主只桥接IMS cursor metadata，实际IC查询/手势必须执行。editor/full scope强制执行原R04字素与结构故障probe，不能只跑研究scope宣布通过。生产未知结果、重复/晚回调、字段/光标变化、同步取消重入、选区/空光标均需保留断言。组件通过仍不能勾选系统I04/D04/I05；历史失败JSON不可替换。

系统宿主增量：bd7ed9a的独立UID宿主在真实选定Pixel上core10/10、private-delete36/36 PASS；没有手工cursor bridge。新增已预冻结privacy-queue20例，包装器只计数/拒绝正文、可延迟真实结构结果，befe红测17/20，所有敏感正文getter0但两续输/长按FAIL。删除后确认屏障修复必须在相同20例及原组件/新增后置故障回归，不因孤立删除通过关闭I05/R04。正文API计数仅涵盖本IC包装边界，不等于所有持久层、日志或EditorInfo正文访问全验收。参考图仍缺，S01—S03不通过。
