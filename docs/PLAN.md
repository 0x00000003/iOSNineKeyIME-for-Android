每阶段验收后更新 STATUS、PROGRESS、测试记录、必要 ADR 和依赖锁并本地提交。任务方框只在有证据时勾选。当前只有 M0 文档工作，不代表应用阶段完成。

## M0 初始化
- [x] 新建独立项目，不覆盖现有路径；记录版本与许可证据。
- [x] 需求/架构/安全/UI/开发/测试/决策/启动说明和机器规格。
- [x] 结构检查与工具自测通过；Git已初始化，首次提交由交付时git记录确认。

- [ ] 检查万象 release zip 中九键依赖闭包，资源文件入口路径正确，选择 t9 而非仅全拼；所有依赖/模型单独确认来源许可和哈希。
