# 本地开发检查点操作说明

当前含临时键盘视图/输入法服务，尚未验收为日用输入法。R04敏感预存组合重音删除仍FAIL；系统服务未启用测试、原图缺失、质量/完整安全/性能未完成。不要据此替换日用键盘或输入真实密码/私人数据。

已在指定Pixel安装本项目debug包，仅运行自有合成宿主；没有启用或切换默认IME。用户醒来后如需检查，由用户在Android系统设置→系统→键盘→屏幕键盘→管理屏幕键盘，亲自启用“离线九键（开发检查点）”并阅读系统警告；在合成文本测试框通过系统输入法切换器选择。代理不得用adb ime enable/set绕过这一步。切回日用键盘也通过系统切换器/设置。没有要求取消锁屏安全或解锁bootloader。

本地冻结debug：`artifacts/m2/m2-debug.apk`，SHA256见同目录SHA256SUMS。该调试签名只用于本项目，不是M6正式交付。unsigned release不可直接安装。需要重新构建时用项目脚本`./scripts/gradle.sh :app:assembleDebug :app:assembleDebugAndroidTest`，工具链/资源来源见DEVELOPMENT和upstream-lock。不要push或上传调试密钥。

操作：中文2–9为T9歧义编码，空闲栏可点常用标点；有组合时空格/回车确认候选；部分选择仍保持组合。展开只显示当前前100候选，前100以外原生分页尚未完成。切英/数/符默认先确认组合；无候选保留组合并可点取消。英文有大/小写；私密、密码及不学习标记只直接英/数、不读取周围文字。中文隐私输入尚未实现，不能称所有场景均已支持。

引擎错误可在栏位点击重试；固定资源损坏可从主应用的探针页重建，保留学习库并隔离原损坏公共目录。该功能不等于“清空学习”，清学习按钮/完整验收尚未完成。宿主未接收的提交仅保留本字段内存，恢复连接后手动重试；切字段丢弃旧pending，避免串入新字段，不承诺跨进程恢复。

隐藏/系统切换按钮通过正常系统流程。停用键盘使用系统设置；卸载仅移除本项目包。不会自动清空其他应用、重置手机、云备份或上传数据。完整安装/清学习/卸载、备份迁移和常用App测试仍待M4/M6记录。
