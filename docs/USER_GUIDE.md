# 使用指南

## 安装和选择

当前为开发版本；构建、签名与兼容范围见[README](../README.md)和[开发手册](DEVELOPMENT.md)。安装 APK 后，通过 Android 的系统输入法设置启用本项目，并在输入法切换器中选择。首次启用会显示 Android 系统警告；切回其他输入法使用同一系统流程，无需修改锁屏安全或解锁 bootloader。

## 输入

中文2–9为九键编码。空闲栏可点常用标点；输入后显示候选，空格/回车可确认首候选。展开候选可分页，收起回第一页。切英文、数字或符号时先确认当前组合；无候选时可修改或取消。

点击“选拼音”选择明确音节，可继续选择剩余音节。“更多”翻页，“返回键盘”保留组合供选词，“取消组合”清除组合。选择音节本身不上屏，最终点击词候选提交；部分选词后也可继续选择剩余音节。该二级页面为项目自身设计。

英文支持大小写；数字、符号、Emoji都有独立面板和返回路径。Emoji固定本地目录与内存搜索，不读取剪贴板或历史。当前不提供离线语音输入。

## 隐私与恢复

密码、私密及不学习字段目前仅直接英文/数字输入，禁止读取周围正文、学习和中文音节查询。敏感退格需要宿主提供必要结构能力；API34以下或不支持相关能力的宿主尚未验收。失败时停止该次编辑，可点“重新连接”；不会自动重放失败退格。WebView限制等见[已知问题](OPEN_ISSUES.md)。

普通字段的本地学习数据可通过主应用“清除学习”确认后清除。公共资源损坏恢复与学习库分开处理。离线来源和许可证可在主应用查看。

隐藏、切换、停用和卸载均使用正常 Android 系统流程。测试结果和未覆盖范围见[当前状态](STATUS.md)。
