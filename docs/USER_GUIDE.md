# 本地开发检查点操作说明

当前是可安装的开发检查点，尚未验收为日用输入法。最新制品、SHA与真实测试范围以[STATUS](STATUS.md)和[选拼音记录](testing/PINYIN_ANDROID-20261024.md)为准；原无障碍坐标、完整多宿主、安全和性能门禁未关闭。

系统测试仅在已启用的本项目debug/优化版之间切换并启动合成宿主；不擅自启用其他条目或绕过系统警告。切回其他键盘使用系统输入法切换器/设置。无需关闭锁屏安全或解锁bootloader。

中文2–9为T9编码；空闲栏可点常用标点；有组合时空格/回车确认首候选。点“选拼音”后点明确音节，可连续选择剩余音节；“更多”翻音节页，“返回键盘”保留组合供选词，“取消组合”清除当前组合。该页采用项目临时设计，没有iOS二级参考；未知格式不给猜测选项。选音节本身不上屏，最终点词候选上屏；部分选词后的未确认部分仍可选音节。

展开候选以20项窗口向真实引擎翻页，收起回第一页，后页空格确认全局首选。切英/数/符默认先确认当前组合；没有候选则保留组合并允许取消。英文支持大小写；数字/符号/Emoji均有实际面板和返回路径。Emoji固定本地目录、内存搜索，不读取用户iPhone历史或剪贴板。语音不在本项目范围，麦克风按钮明确提示未提供离线语音。

私密、密码及不学习标记仅直接英/数输入，不读周围正文、不产生中文音节查询。退格使用必要结构位置/边界，不保存结构数据；异步等待期间续输排队，长按重复不积压。未知、不支持或超时结果停止该次编辑，不用截断字素的DEL掩盖限制。API34以下和不提供结构能力的宿主仍未验收，私密中文候选尚未提供。

主应用提供离线来源/许可和“清除学习”显式确认。只允许清除停止的正常IME私有学习目录，已有十组合成清除/重启组件证据；不能据此称完整系统安全已验收。公共资源损坏可隔离重建，保留学习库。宿主未接收的提交仅保留当前字段内存，切字段丢弃旧pending，避免串字。

隐藏、切换、停用使用正常系统流程；卸载仅移除本项目包，不清其他应用、不重置手机、不上传数据。调试密钥仅在项目私有目录；显式`-PlocalReleaseProbe=true`构建优化本地测试包，默认release仍unsigned，两者都不是正式交付签名。
