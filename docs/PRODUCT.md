# 产品需求与验收

## 范围与取舍
面向使用 Android、熟悉 iPhone 原生九宫格的中文输入用户。参照的是特定 iOS 版本和键盘设置，不能仅凭机型确定界面。获得原图后记录 iOS 版本、简体拼音九宫格、深浅色、显示缩放、输入框类型与横竖屏；Android 记录 OS/API、屏幕模式、密度、字体比例、导航方式、键盘高度。绝对像素不能跨设备直接复刻，以可用区域归一化、触控习惯和状态行为作为依据。

P0 = 核心与隐私，不允许降级；P1 = 首次完整交付需要；P2 = 后续增强。语音、云同步、在线更新、账号、广告、跨 App 收集上下文不在范围。基础英文、数字、符号和 IME action 仍在范围，以便日常输入不被困住。系统授权提示使用 Android 原生流程。

## 性能预算（待实测，不是承诺已有结果）
Pixel 9 Pro 同一 Android/屏幕配置、release arm64-v8a、非热降频条件：预热后1000次合成输入，按下到按键反馈 P95≤32ms；按键到候选更新 P95≤80ms、P99≤150ms；键盘冷启动20次 P95≤800ms（已完成数据首次部署）；5000次压力输入无崩溃/ANR/丢失或重复提交；连续30分钟后 private dirty/PSS 无持续增长，PSS 暂定≤350MiB。约398MB模型不能凭文件体积推断 RSS，须同时量 mmap/PSS 和部署耗时。首次部署另计20次，暂定≤30秒、可见进度且主线程不阻塞；超预算须分析并记录优化，不悄悄改门槛。刷新率不同记录帧时间，触感由用户评估。

## 发布门禁
P0/P1 全部对应 PASS 或明确未交付；不得以“预计支持”代替实测。无截图/真机不能关闭 R13/设备安全测试；可交付开发检查点。相同 APK 哈希绑定每次测试，至少一个 release 构建覆盖主机、集成、视觉、真机、性能、安全、回归；发现回归后修复并重跑受影响集合。
