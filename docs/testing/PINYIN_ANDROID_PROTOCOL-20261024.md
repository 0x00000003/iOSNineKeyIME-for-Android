# 选拼音 Android 接入协议（实现/测量前冻结）

先验证纯状态与防陈旧、再真实 Android JNI/触控组件、最后独立UID宿主真实系统IME触屏。固定合成输入和预期只留测试源码，不在结果、日志/Git证据输出输入/候选/设备标识。原无障碍门禁不降级、不被像素scope替代。

断言：查询只读无宿主commit，真实注释导出不同音节；选择第一/第二音节产生正确混合/明确拼音且无自动commit，最终选词恰好提交一次；换前缀确实改变候选。部分选词后选择剩余音节，已确认段保留且最终无重复提交。session/revision/raw任一过期拒绝、伪造范围拒绝、私密禁用、取消/隐藏/切字段清除音节缓存，异步续输保持顺序。普通键不额外批量查询100候选；仅用户打开选拼音或继续选音节按需查询最多100条。

组件必须用真实串行JNI和生产NineKeyView/Controller，不能只直接调用helper。系统测试使用实际屏幕触点和独立宿主正文oracle，不能生产事件桥；真实选择至少完成一组双音节词和部分选词组合。拿不到系统窗口坐标时使用既有物理scope的独立屏幕几何，保留原a11y FAIL。必要时增加截图只截自有合成键盘，原图忽略不提交。

不新增工具链或模型副本，复用在用SDK/NDK/Gradle/native build。只构建必要增量，记录主/测试/宿主APK SHA及nonce；失败记录保存，修复后同断言重测。当前无iOS二级选拼音参考，页面标临时实现，不称该页面1:1。

系统v1真实触屏前三项通过，展开候选后按五态参考总高判定失败（新页实际为988px、原九键920px）。展开候选没有iOS参考，新增scope改以自身稳定inset/三帧和四行实际色块边界验证可触目标；原五态高度断言及原a11y门禁保持原样。只对新选拼音测试中的展开候选页启用该独立检查，不称该页参考视觉通过。候选/音节仅通过自有可访问UI标签识别，触屏坐标来自实际屏幕几何/色块，不读生产内部状态，不修正或继承错误a11y坐标。
