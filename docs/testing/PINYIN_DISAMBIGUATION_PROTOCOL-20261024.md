# 选拼音兼容性探针（运行前冻结）

先复用现有Mac原生librime构建/固定万象schema与compact模型，不复制工具链或词库；独立新合成profile。此为构建主机API兼容性，不算Android/系统IME通过。只输出布尔、数量与版本/文件SHA，不输出输入、候选或拼音正文。

固定合成断言：64426可得到预期词，真实候选comment带可解析音节；set_input将原数字组合改为ni+剩余数字时，raw input精确改变、仍有候选、无自动commit；再改第二音节为hao，精确选词仅一次且无重复commit。另检查替代mi前缀确实排除原目标词。部分选择你好后，对尚未确认的世界数字部分改为shi+剩余数字，确认原已选前缀保留，最终累计仅一次你好世界；不得通过清空整段/重新提交前缀伪装保留。

通过后才考虑生产接入。设计要求：按session/revision和原raw input三重防陈旧；只编辑未确认数字范围，保留已选词与当前Rime会话/历史；私密模式不产生此native操作；纯状态/失效选项/异步队列/部分选词及真实Android JNI均需另测。未知iOS二级选拼音页面只能标临时交互，不宣称1:1。失败先明确API/数据限制，不以文字说明或展开汉字候选冒充选拼音。
