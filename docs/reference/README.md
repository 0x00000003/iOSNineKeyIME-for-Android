# 参考资料

## 外观参考

外观测量参考五张深色iPhone原生键盘图片，覆盖中文九宫格、数字、符号、英文和Emoji。测量元数据位于 `spec/reference/ios-dark-v1.json`，包含参考环境、原始尺寸、键盘边界及SHA256；缩放/文字设置和未展示交互分别标注未知。

私人原件不纳入Git或APK；测量、标注与裁图保持独立。公开README使用本项目Android实际运行截图，见[截图来源](../images/README.md)，不以iOS截图冒充Android实现。

## 上游证据

`upstream/`保存固定commit的许可证、构建/清单/schema等研究快照与来源元数据，保持原作者许可证和原始字节。它们不是运行时安全验收结果；实际集成和修改见[上游说明](../UPSTREAM.md)、[来源锁](../../upstream-lock.json)及 `third_party/`。
