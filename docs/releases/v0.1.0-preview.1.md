## 安装与启用

1. 在 ARM64 Android 手机上下载上述 `.apk`，点击安装；若系统询问，允许当前浏览器或文件管理器安装此下载文件。安装完成后可关闭该来源的安装权限。
2. 打开“离线九键（优化测试版）”，点击“系统键盘设置（由你启用/切换）”，在系统设置中启用本输入法。首次启用须由你阅读并确认 Android 的输入法警告。
3. 打开任意可输入文本的页面，使用系统键盘切换器选择“离线九键（优化测试版）／简体中文九键（开发检查点）”。不必运行应用中的“合成探针”按钮。
4. 首次显示键盘时等待内置资源部署；如失败，回到应用查看固定错误提示，可使用“重建内置资源（保留学习库）”。不要用“清空学习”代替资源修复。

系统设置入口因厂商不同，通常位于“设置 → 系统／更多设置 → 语言和输入法 → 屏幕键盘／管理键盘”。恢复原键盘使用相同的系统切换入口。

如安装提示签名冲突，先切回其他键盘；卸载旧版会删除本地学习数据，确认可以丢弃后再卸载重装。本包使用调试证书，后续正式签名版可能无法覆盖安装，也不保证本地学习数据能迁移。

## 功能与已验证范围

支持中文九键、候选分页、逐音节选拼音、空闲标点，以及数字、符号、英文和 Emoji；普通字段支持本地学习，当前没有语音输入。

本 APK 的既有真机记录：选拼音 8/8、旋转 7/7、采图时五态触屏 9/9 通过。发布前再次核对原包 SHA256、v1/v2 签名、权限、旧新备份 XML、锁定资源哈希和零打包字体，静态审计通过。本次没有重跑全量真机或首次安装离线测试，不将其他 APK 的成绩归给本包。

## 已知问题与未覆盖范围

- **部分 WebView 密码框无法正常退格**：当前记录 2/3，密码结构删除失败。出现“编辑失败”后可点“重新连接”继续输入；此操作不会补做失败的删除。遇到该问题请切换其他系统键盘。
- **无障碍与宿主兼容尚不完整**：原系统无障碍窗口坐标／部分生命周期门禁失败；邮箱宿主出现外部焦点干扰，未完成输入断言；TalkBack 未完成验收。
- **敏感字段有功能限制**：密码／私密／不学习字段目前只支持直接英文或数字，不支持私密中文候选；退格依赖宿主提供结构能力，Android 14 / API 34 以下尚未完整支持。Compose、复杂跨行和 RTL 场景未完整覆盖。
- **外观并非完全一致**：主要覆盖深色布局；浅色、字体缩放、动画和更多状态尚未完整验证。系统字体、Emoji、导航和部分交互与 iOS 有差异。
- **完整发布门禁未关闭**：性能、全路径运行时隐私／安全、当前包首次安装离线、目标系统备份／迁移、同 APK 全量回归，以及词库二次来源、模型对应源与分发许可闭包审查仍有未完成项目。

完整清单见[已知问题](https://github.com/0x00000003/iOSNineKeyIME-for-Android/blob/v0.1.0-preview.1/docs/OPEN_ISSUES.md)。反馈请附本版本、Android 版本、宿主应用与合成内容复现步骤，不要上传密码、私人聊天或用户词库。
